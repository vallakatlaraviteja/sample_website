About TerraPulse

A live 3D map of new AI/ML repositories on GitHub, geo-located to their authoring organisation.

  • AI launches — repos created in the last 30 days with at least 30 stars matching AI/ML keywords. Pulled live from the GitHub Search API and classified into LLM / Vision / Audio / Agents / Framework / Other.
  • Time scrubber — filter to the last 1–30 days. Recent launches arrive with animated arcs.
  • Hover a repo to see other repos by the same owner. Click to open on GitHub.
  • Quakes — last-24h feed from USGS. Magnitude ≥5 events get a shockwave ring.
  • ISS — current location plus the orbital trail of the last few minutes via wheretheiss.at.

Org coordinates are a curated list of ~40 major AI labs. Repos from un-mapped owners are not shown — by design, no fabricated coordinates.

Static demo. The full version (sign-in with GitHub, moderated community pulses, daily email alerts, Stripe-backed Verified tier) is in the same repo and deploys to Render via render.yaml.
